# PLOPLAZ

Sparatutto in terza persona contro gli zombie, ambientato nelle Backrooms di Azzanello. Si gioca nel browser, senza installare niente.

**Gioca:** apri `index.html` dal sito GitHub Pages del repository.

## Comandi

| Tasto | Azione |
|---|---|
| W A S D | muoviti |
| Mouse | guarda |
| Clic sinistro | spara |
| Clic destro (tieni) | mira |
| 1–5 · Q · rotellina | cambia arma |
| G | granata |
| B | bevi una Ichnusa (10 s di invincibilità) |
| V · F | colpo col calcio |
| C | accucciati |
| Shift | corri |
| Spazio | salta |
| R | ricarica |
| Esc | pausa |
